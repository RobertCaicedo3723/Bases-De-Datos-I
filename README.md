# Bases-De-Datos-I

🎬 Proyecto Base de Datos – Sistema de Gestión de Cine
📌 Descripción

Este proyecto consiste en el diseño e implementación de una base de datos relacional para la gestión de un cine.
Incluye la creación de tablas, inserción de datos, consultas SQL, actualizaciones y ejemplos prácticos documentados en un manual de usuario.

El sistema permite gestionar:

🎥 Películas

🏢 Salas

🎭 Espectáculos

💳 Membresías

📊 Consultas y filtrados con sentencias SQL

🛠️ Tecnologías Utilizadas

SQL Server

T-SQL

Microsoft Excel (modelo preliminar)

Git & GitHub
